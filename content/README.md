# JupyterLite A2UI tests

Open [smoke_test.ipynb](./smoke_test.ipynb) on Python (Pyodide) or Python
(XPython). Run its setup cell and surface cell, submit a name, and check the
confirmation and action payload. The example notebooks `01` to `06` use the
same setup cell.

Open [a2ui-js-form-submit.ipynb](./a2ui-js-form-submit.ipynb) with the
JavaScript kernel and repeat the same test. The adapter loads from the
same JupyterLite site, including when it is hosted under a URL prefix.

The [source repository](https://github.com/MRYingLEE/a2ui-jupyterlite-demo/tree/jupyter-js-kernel) documents
the deployment inputs and kernel setup.
