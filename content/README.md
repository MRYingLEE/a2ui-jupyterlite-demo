# JupyterLite A2UI Python tests

Open [smoke_test.ipynb](./smoke_test.ipynb) on Python (Pyodide) or Python
(XPython). Run its setup cell and surface cell, submit a name, and check the
confirmation and action payload. The example notebooks `01` to `06` use the
same setup cell.

The [source repository](https://github.com/MRYingLEE/jupyterlite-demo) documents
the deployment inputs and kernel setup. JavaScript-kernel tests are on the
`jupyter-js-kernel` branch.
