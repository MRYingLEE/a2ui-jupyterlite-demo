# JupyterLite A2UI Python tests

Open [a2ui-test-pyodide.ipynb](./a2ui-test-pyodide.ipynb) for Python (Pyodide)
or [a2ui-test-xeus.ipynb](./a2ui-test-xeus.ipynb) for Python (XPython). Run
its cells, submit a name, and check the confirmation and action payload.

The [source repository](https://github.com/MRYingLEE/jupyterlite-demo) documents
the deployment inputs and kernel setup. JavaScript-kernel tests are on the
`jupyter-js-kernel` branch.
